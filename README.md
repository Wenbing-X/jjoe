# AI Project Manager Portfolio

谢文炳的 AI 项目经理个人网站，展示 AI 内容项目、生成式工作流与项目推进能力。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 替换内容

- 个人履历、项目与联系方式：`src/App.jsx`
- 项目列表与项目图片：`src/App.jsx` 顶部的 `projects`
- 主视觉视频：替换 Hero 中 `<source>` 的地址，或放入 `public` 后使用本地路径
- 色彩、字体、版心和响应式样式：`src/styles.css`

网站内容已根据 2026 年 8 月提供的中文简历调整；项目视觉图仍为可替换的演示素材。
